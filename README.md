# OK.PHOTOWORK

Single-file photography site (`index.html`): home, portfolio, journal, about, contact,
a private client gallery with star ratings and notes, and an admin editor.

## Notes
- The admin editor, client login, ratings and uploads rely on the claude.ai artifact
  runtime (database, assets, user). They only work when the page is hosted as a claude.ai artifact.
- Anywhere else (for example GitHub Pages) the public pages still work and show the built-in
  default content.
- Photos on the default content are illustrations drawn in code.
